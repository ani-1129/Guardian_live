# Contributing Guidelines

Thank you for contributing to Guardian Live Enterprise!

## Local Development Flow
1. Fork and clone the repository.
2. Follow instructions in [DeveloperGuide.md](file:///d:/internship/location/docs/DeveloperGuide.md) to set up python and node environments.
3. Write modular changes. Ensure there are corresponding tests in `backend/tests` or `frontend/tests`.
4. Run code linters (`black`, `flake8`, `eslint`).
5. Open a Pull Request referencing the issue or feature.
